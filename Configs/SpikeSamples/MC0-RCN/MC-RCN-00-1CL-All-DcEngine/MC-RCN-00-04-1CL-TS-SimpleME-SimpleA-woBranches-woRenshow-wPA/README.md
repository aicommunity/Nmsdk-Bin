## MC-RCN-00-04-1CL-TS-SimpleME-SimpleA-woBranches-woRenshow-wPA — одноуровневый рефлекторный контур с TS-SimpleME

**Путь:** `Bin/Configs/SpikeSamples/MC0-RCN/MC-RCN-00-1CL-All-DcEngine/MC-RCN-00-04-1CL-TS-SimpleME-SimpleA-woBranches-woRenshow-wPA`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **одноуровневый рефлекторный контур (RCN)** для управления DC-двигателем с двигательным элементом типа TS:
- **Двигательный элемент типа TS (TS-SimpleME)** — отличие от базовой конфигурации
- Простая афферентация (SimpleA)
- Без ветвления афферентных путей (woBranches)
- Без клеток Реншоу (woRenshow)
- С пресинаптическим торможением (wPA)

Согласно [A] и `MuscleControlStructures.md`, двигательный элемент типа TS имеет отличия в структуре и параметрах по сравнению с простым двигательным элементом. Данная конфигурация позволяет изучать влияние типа двигательного элемента на работу рефлекторных контуров.

### Отличия от базовой конфигурации

Данная конфигурация отличается от `MC-RCN-00-01` использованием двигательного элемента типа TS (TS-SimpleME вместо SimpleME). Влияние типа двигательного элемента:
- Различия в структуре двигательного элемента
- Различия в параметрах обработки сигналов
- Возможные различия в характеристиках управления
