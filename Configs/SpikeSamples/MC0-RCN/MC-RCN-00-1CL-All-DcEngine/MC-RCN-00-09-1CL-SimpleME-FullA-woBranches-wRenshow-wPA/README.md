## MC-RCN-00-09-1CL-SimpleME-FullA-woBranches-wRenshow-wPA — одноуровневый рефлекторный контур с полной афферентацией и клетками Реншоу

**Путь:** `Bin/Configs/SpikeSamples/MC0-RCN/MC-RCN-00-1CL-All-DcEngine/MC-RCN-00-09-1CL-SimpleME-FullA-woBranches-wRenshow-wPA`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **одноуровневый рефлекторный контур (RCN)** для управления DC-двигателем с полной афферентацией и клетками Реншоу:
- Простой двигательный элемент (SimpleME)
- Полная афферентация (FullA)
- Без ветвления афферентных путей (woBranches)
- **С клетками Реншоу (wRenshow)** — отличие от MC-RCN-00-07
- С пресинаптическим торможением (wPA)

Согласно [A] и `MuscleControlStructures.md`, комбинация полной афферентации с клетками Реншоу позволяет изучать влияние возвратного торможения на работу рефлекторных контуров с полной обработкой сенсорной информации.

### Отличия от других конфигураций

Данная конфигурация отличается от `MC-RCN-00-07` наличием клеток Реншоу (wRenshow). Комбинация FullA с клетками Реншоу:
- Стабилизирует частоту разрядов мотонейронов через возвратное торможение
- Обеспечивает возвратное торможение при использовании полной афферентации
- Может улучшить стабильность управления за счёт комбинации полной информации и стабилизации частоты разрядов
