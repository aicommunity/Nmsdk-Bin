## MC-RCN-00-06-1CL-TS-SimpleME-SimpleA-woBranches-wRenshow-wPA — одноуровневый рефлекторный контур с TS-SimpleME и клетками Реншоу

**Путь:** `Bin/Configs/SpikeSamples/MC0-RCN/MC-RCN-00-1CL-All-DcEngine/MC-RCN-00-06-1CL-TS-SimpleME-SimpleA-woBranches-wRenshow-wPA`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **одноуровневый рефлекторный контур (RCN)** для управления DC-двигателем с двигательным элементом типа TS и клетками Реншоу:
- Двигательный элемент типа TS (TS-SimpleME)
- Простая афферентация (SimpleA)
- Без ветвления афферентных путей (woBranches)
- **С клетками Реншоу (wRenshow)** — отличие от MC-RCN-00-04
- С пресинаптическим торможением (wPA)

Согласно [A] и `MuscleControlStructures.md`, комбинация TS-SimpleME с клетками Реншоу позволяет изучать влияние возвратного торможения на работу рефлекторных контуров с двигательным элементом типа TS.

### Отличия от других конфигураций

Данная конфигурация отличается от `MC-RCN-00-04` наличием клеток Реншоу (wRenshow). Комбинация TS-SimpleME с клетками Реншоу:
- Стабилизирует частоту разрядов мотонейронов через возвратное торможение
- Обеспечивает возвратное торможение для двигательного элемента типа TS
- Может улучшить стабильность управления
