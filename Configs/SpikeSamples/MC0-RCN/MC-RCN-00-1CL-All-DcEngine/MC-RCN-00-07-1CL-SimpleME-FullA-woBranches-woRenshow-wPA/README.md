## MC-RCN-00-07-1CL-SimpleME-FullA-woBranches-woRenshow-wPA — одноуровневый рефлекторный контур с полной афферентацией

**Путь:** `Bin/Configs/SpikeSamples/MC0-RCN/MC-RCN-00-1CL-All-DcEngine/MC-RCN-00-07-1CL-SimpleME-FullA-woBranches-woRenshow-wPA`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **одноуровневый рефлекторный контур (RCN)** для управления DC-двигателем с полной афферентацией:
- Простой двигательный элемент (SimpleME)
- **Полная афферентация (FullA)** — отличие от базовой конфигурации
- Без ветвления афферентных путей (woBranches)
- Без клеток Реншоу (woRenshow)
- С пресинаптическим торможением (wPA)

Согласно [A] и `MuscleControlStructures.md`, полная афферентация включает все типы афферентных каналов (Ia, II, Ib), что позволяет более полную обработку сенсорной информации по сравнению с простой афферентацией.

### Отличия от базовой конфигурации

Данная конфигурация отличается от `MC-RCN-00-01` использованием полной афферентации (FullA вместо SimpleA). Влияние полной афферентации:
- Включает все типы афферентных каналов (Ia, II, Ib)
- Позволяет более полную обработку сенсорной информации
- Может улучшить характеристики управления за счёт более полной информации о состоянии объекта управления
