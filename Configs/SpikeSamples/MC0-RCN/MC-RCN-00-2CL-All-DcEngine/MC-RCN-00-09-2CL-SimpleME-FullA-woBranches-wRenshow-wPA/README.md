## MC-RCN-00-09-2CL-SimpleME-FullA-woBranches-wRenshow-wPA — двухуровневый рефлекторный контур

**Путь:** `Bin/Configs/SpikeSamples/MC0-RCN/MC-RCN-00-2CL-All-DcEngine/MC-RCN-00-09-2CL-SimpleME-FullA-woBranches-wRenshow-wPA`  
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **двухуровневый рефлекторный контур (RCN)** для управления DC-двигателем с двумя контурами управления:
- Простой двигательный элемент (SimpleME), Полная афферентация (FullA), Без ветвления (woBranches), С клетками Реншоу (wRenshow), С пресинаптическим торможением (wPA)
- **Двухуровневая структура (2CL)** — два контура управления (например, по углу и скорости)

Согласно [A] и `MuscleControlStructures.md`, двухуровневые контуры обеспечивают более точное управление за счёт использования нескольких сенсорных сигналов. Данная конфигурация аналогична `MC-RCN-00-09-1CL-SimpleME-FullA-woBranches-wRenshow-wPA` из группы `MC-RCN-00-1CL-All-DcEngine`, но использует два контура управления вместо одного.

### Отличия от одноуровневой конфигурации

Данная конфигурация отличается от `MC-RCN-00-09-1CL-SimpleME-FullA-woBranches-wRenshow-wPA` из группы `MC-RCN-00-1CL-All-DcEngine` использованием двух контуров управления (2CL вместо 1CL):
- Два контура управления позволяют использовать несколько сенсорных сигналов (например, угол и скорость)
- Более точное управление за счёт комбинации нескольких сенсорных входов
- Более сложная структура, требующая координации между контурами

### Структура двухуровневого рефлекторного контура

Двухуровневый рефлекторный контур содержит два контура управления, каждый из которых обрабатывает свой сенсорный сигнал и формирует управляющее воздействие. Контуры могут работать параллельно или последовательно, обеспечивая более точное управление объектом.
