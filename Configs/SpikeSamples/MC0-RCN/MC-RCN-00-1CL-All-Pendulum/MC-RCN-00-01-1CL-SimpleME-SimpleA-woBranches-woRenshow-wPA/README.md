## MC-RCN-00-01-1CL-SimpleME-SimpleA-woBranches-woRenshow-wPA — базовый одноуровневый рефлекторный контур с маятником

**Путь:** `Bin/Configs/SpikeSamples/MC0-RCN/MC-RCN-00-1CL-All-Pendulum/MC-RCN-00-01-1CL-SimpleME-SimpleA-woBranches-woRenshow-wPA`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **базовый одноуровневый рефлекторный контур (RCN)** для управления маятником с минимальной структурой:
- Простой двигательный элемент (SimpleME)
- Простая афферентация (SimpleA)
- Без ветвления афферентных путей (woBranches)
- Без клеток Реншоу (woRenshow)
- С пресинаптическим торможением (wPA)

Согласно [A] и `MuscleControlStructures.md`, данная конфигурация аналогична `MC-RCN-00-01-1CL-SimpleME-SimpleA-woBranches-woRenshow-wPA` из группы `MC-RCN-00-1CL-All-DcEngine`, но использует модель маятника вместо DC-двигателя в качестве объекта управления. Использование модели маятника позволяет изучать работу рефлекторных контуров на более простом объекте управления.

### Структура конфигурации

Конфигурация содержит:
- **Pendulum** (`NPendulumAndCart` или аналогичный компонент) — маятник как объект управления
- **EngineControlRangeAfferent** — двигательный элемент с простой афферентацией

### Отличия от конфигурации с DC-двигателем

Данная конфигурация отличается от `MC-RCN-00-01-1CL-SimpleME-SimpleA-woBranches-woRenshow-wPA` из группы `MC-RCN-00-1CL-All-DcEngine` использованием модели маятника вместо DC-двигателя:
- Маятник является более простым объектом управления, что упрощает анализ влияния структурных параметров
- Модель маятника позволяет изучать работу рефлекторных контуров на объекте с более простой динамикой
- Параметры обратной связи могут отличаться (угол и скорость вместо угла, скорости и момента)
