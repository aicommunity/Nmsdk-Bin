## MC-RCN-00-02-1CL-SimpleME-SimpleA-wBranches-woRenshow-wPA — одноуровневый рефлекторный контур с маятником

**Путь:** `Bin/Configs/SpikeSamples/MC0-RCN/MC-RCN-00-1CL-All-Pendulum/MC-RCN-00-02-1CL-SimpleME-SimpleA-wBranches-woRenshow-wPA`  
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **одноуровневый рефлекторный контур (RCN)** для управления маятником:
- Простой двигательный элемент (SimpleME), Простая афферентация (SimpleA), С ветвлением афферентных путей (wBranches), Без клеток Реншоу (woRenshow), С пресинаптическим торможением (wPA)

Согласно [A] и `MuscleControlStructures.md`, данная конфигурация аналогична `MC-RCN-00-02-1CL-SimpleME-SimpleA-wBranches-woRenshow-wPA` из группы `MC-RCN-00-1CL-All-DcEngine`, но использует модель маятника вместо DC-двигателя в качестве объекта управления. Использование модели маятника позволяет изучать работу рефлекторных контуров на более простом объекте управления.

### Отличия от конфигурации с DC-двигателем

Данная конфигурация отличается от аналогичной конфигурации из группы `MC-RCN-00-1CL-All-DcEngine` использованием модели маятника вместо DC-двигателя:
- Маятник является более простым объектом управления, что упрощает анализ влияния структурных параметров
- Модель маятника позволяет изучать работу рефлекторных контуров на объекте с более простой динамикой
- Параметры обратной связи могут отличаться (угол и скорость вместо угла, скорости и момента)
