## MC-M-01-EyeMuscle — модель управления мышцей глаза (расширенная)

**Путь:** `Bin/Configs/SpikeSamples/MC-Muscles/MC-M-01-EyeMuscle`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **расширенную модель управления мышцей глаза** на основе нейронных команд. Конфигурация использует компонент `NEyeMuscle` для моделирования движения глаз на основе импульсных сигналов от генератора (`NPGenerator`) с частотой 8 Гц и включает компонент `UStatisticDoubleMatrix` для сбора статистики о работе мышцы.

Согласно `MuscleControlStructures.md` и публикациям [1], [13], [31], модели мышц являются важной частью нейронных структур управления движением. Данная конфигурация расширяет базовую модель `MC-M-00-EyeMuscle` возможностью сбора статистики и использованием более высокой частоты входных сигналов.
  [31]
  ([онлайн-описание](https://neuromodeler.ru/index.php?option=com_content&view=article&id=29:1&catid=67&lang=ru&Itemid=676))

### Структура конфигурации

Конфигурация содержит:

- **PGenerator** (`NPGenerator`) — генератор импульсных сигналов
  - `Frequency` = 8 Гц — частота генерации импульсов (выше, чем в базовой версии)
  - `Amplitude` = 1 — амплитуда импульсов
  - `PulseLength` = 0.001 с — длительность импульса
  - `AvgInterval` = 5 с — средний интервал между импульсами
- **EyeMuscle** (`NEyeMuscle`) — модель мышцы глаза, преобразующая импульсные сигналы в движение глаза
- **StatisticDoubleMatrix** (`UStatisticDoubleMatrix`) — компонент для сбора статистики о работе мышцы

### Биологическая мотивация

Согласно `MuscleControlStructures.md` и публикациям [1], [13], [31]:

#### Компоненты управления мышцами

- **Мотонейроны** — иннервируют мышечные волокна, передавая импульсные команды
- **Мышцы** — преобразуют нейронные команды в механическое движение
- **Обратная связь** — сенсорные сигналы от мышц используются для контроля движения

#### Управление движением глаз

- Движение глаз контролируется системой глазодвигательных мышц
- Нейронные команды преобразуются в сокращения мышц, что приводит к движению глаз
- Модель `NEyeMuscle` реализует преобразование импульсных сигналов в движение глаза

### Эксперимент и моделируемые реакции

#### Цель эксперимента

Изучение преобразования нейронных команд в движение мышц с расширенными возможностями:
- Преобразование импульсных сигналов в мышечные сокращения
- Влияние частоты импульсов на движение глаза
- Сбор статистики о работе мышцы для анализа

#### Сценарии экспериментов

1. **Расширенное управление мышцей:**
   - Генератор импульсов создаёт периодические сигналы с частотой 8 Гц
   - Мышца глаза преобразует импульсные сигналы в движение
   - Компонент статистики собирает данные о работе мышцы
   - Наблюдение зависимости движения от частоты входных сигналов

2. **Влияние частоты импульсов:**
   - Изменение частоты генератора импульсов
   - Наблюдение влияния на движение глаза
   - Анализ статистики для различных частот
   - Сравнение с базовой версией (MC-M-00-EyeMuscle)

3. **Анализ статистики:**
   - Сбор статистики о работе мышцы
   - Анализ влияния различных параметров на характеристики движения
   - Изучение динамики работы мышцы

#### Ожидаемые результаты

- **Преобразование сигналов:** импульсные сигналы должны преобразовываться в движение глаза
- **Зависимость от частоты:** увеличение частоты импульсов должно приводить к изменению характеристик движения
- **Статистика:** компонент статистики должен собирать данные о работе мышцы для анализа

### Параметры модели

Основные параметры задаются в `Parameters.xml`:

#### Параметры генератора импульсов

- **Frequency:** 8 Гц (частота генерации импульсов, выше чем в базовой версии)
- **Amplitude:** 1 (амплитуда импульсов)
- **PulseLength:** 0.001 с (длительность импульса)
- **AvgInterval:** 5 с (средний интервал между импульсами)

#### Параметры мышцы глаза

- Параметры преобразования импульсных сигналов в движение
- Параметры модели мышцы глаза
- Параметры обратной связи

#### Параметры статистики

- Параметры сбора статистики о работе мышцы
- Параметры обработки данных

Точные численные значения можно смотреть в `Parameters.xml`.

### Отличия от MC-M-00-EyeMuscle

Данная конфигурация является расширенной версией модели управления мышцей глаза. Отличия от базовой версии `MC-M-00-EyeMuscle`:
- Более высокая частота генератора импульсов (8 Гц вместо 1 Гц)
- Добавлен компонент статистики (`UStatisticDoubleMatrix`) для сбора данных о работе мышцы
- Расширенные возможности для анализа работы мышцы
