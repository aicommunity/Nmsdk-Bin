## NM-PN-08-LtmNeuron-3M1St3In3 — нейрон с длительной мембранной памятью (3M, 1St, 3In)

**Путь:** `Bin/Configs/SpikeSamples/NM-Neurons/NM-PN-08-LtmNeuron-3M1St3In3`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация реализует **спайковый нейрон с длительной мембранной памятью (LTM)** с тремя соматическими участками мембраны (3M), одним синапсом (1St) и тремя входными каналами (3In3). Она демонстрирует влияние комбинации длительной мембранной памяти и увеличенного размера сомы на реакции нейрона.

Согласно исследованиям реакций естественных нейронов, длительная мембранная память в сочетании с увеличенным размером сомы позволяет реализовать более сложные паттерны обработки информации. Данная конфигурация позволяет изучать взаимодействие между мембранной памятью и структурными параметрами нейрона.

### Структура модели

- **Нейрон:** `NNewLPNeuron` (специализированный нейрон с длительной мембранной памятью)
  - три соматических участка мембраны (`PNeuronMembrane`, `PNeuronMembrane2`, `PNeuronMembrane3`);
  - длительная мембранная память (`LTMembrane`);
  - низкопороговая зона `NPulseLTZone` (генератор спайков);
  - генераторы возбуждающего и тормозного потенциалов `NConstGenerator`.
- **Мембраны:** `NPulseMembrane` / `NPulseMembraneCommon`
  - три соматических участка мембраны, каждый с парой ионных каналов;
  - длительная мембранная память с каналами и синапсами;
  - возбуждающие каналы `ExcChannel` (`NPExcChannel`, Type = −1);
  - тормозные каналы `InhChannel` (`NPInhChannel`, Type = +1).
- **Синапсы:** `NPulseSynapse` / `NPulseSynapseCommon`
  - один возбуждающий синапс, подключённый к возбуждающему каналу.

Упрощённая схема:

```mermaid
flowchart TD
    inputSpike1["Входной импульсный поток 1"] --> syn["NPulseSynapse"]
    inputSpike2["Входной импульсный поток 2"] --> syn
    inputSpike3["Входной импульсный поток 3"] --> syn
    syn --> excCh["ExcChannel\n(NPExcChannel, Type < 0)"]
    excCh --> ltm["LTMembrane\n(длительная память)"]
    ltm --> membr1["NPulseMembrane\n(сома участок 1)"]
    ltm --> membr2["NPulseMembrane2\n(сома участок 2)"]
    ltm --> membr3["NPulseMembrane3\n(сома участок 3)"]
    membr1 --> lt["NPulseLTZone\n(порог P)"]
    membr2 --> lt
    membr3 --> lt
    lt --> outSpike["Выходной спайковый поток"]
    outSpike -->|обратная связь| membr1
    outSpike -->|обратная связь| membr2
    outSpike -->|обратная связь| membr3
    ltm -.->|влияние памяти| membr1
    ltm -.->|влияние памяти| membr2
    ltm -.->|влияние памяти| membr3
```

### Структурная и параметрическая адаптация

Согласно [A], модель нейрона со структурной адаптацией позволяет динамически изменять структуру связей между элементами нейрона. В данной конфигурации:

- **Структурная адаптация:** фиксированная структура с тремя соматическими участками и длительной мембранной памятью, демонстрирующая влияние памяти на реакции нейрона с увеличенной сомой.
- **Параметрическая адаптация:** параметры мембраны, каналов и синапсов могут настраиваться для изучения различных режимов работы с памятью.

### Пластичность модели

Пластичность модели нейрона (раздел 2.5 диссертации Бахшиева) обеспечивается возможностью изменения весов синапсов и параметров мембраны. В данной конфигурации пластичность проявляется через:

- изменение эффективности синаптической передачи;
- адаптацию параметров мембраны к входным сигналам;
- формирование различных паттернов активности в зависимости от состояния длительной памяти и структуры сомы.

### Эксперимент и моделируемые реакции

- **Вход:** последовательности импульсов фиксированной амплитуды и длительности на трёх возбуждающих входах.
- **Наблюдаемые величины:**
  - частота выходных спайков;
  - форма мембранного потенциала на входе LT‑зоны;
  - влияние частоты входной стимуляции на число спайков в пачке;
  - влияние длительной мембранной памяти на реакции нейрона;
  - сравнение с конфигурациями без длительной памяти (NM-PN-04) и с меньшим числом участков (NM-PN-07).
- **Ожидаемое поведение:**
  - при умеренных частотах входа нейрон генерирует пачки спайков;
  - длительная мембранная память влияет на реакции нейрона на последующие стимулы;
  - увеличение числа соматических участков приводит к снижению частоты генерации по сравнению с конфигурацией с одним участком;
  - возможен эффект накопления информации в мембранной памяти и пространственной суммации сигналов от разных участков.

### Параметры модели

Основные параметры задаются в `Parameters.xml`:

- **Синапс (`NPulseSynapse`):**
  - `PulseAmplitude` — амплитуда входных импульсов;
  - `SecretionTC`, `DissociationTC` — постоянные времени выделения и распада медиатора;
  - `InhibitionCoeff`, `Resistance`, `UsePresynapticInhibition` — эффекты пресинаптического торможения.
- **Канал (`NPulseChannel`):**
  - `Capacity`, `Resistance`, `FBResistance`, `RestingResistance`;
  - `Type` = −1 для возбуждающего канала.
- **Мембрана и LT‑зона:**
  - `FeedbackGain` — глубина обратной связи;
  - порог LT‑зоны `P` и временные константы генератора;
  - параметры для каждого из трёх соматических участков;
  - параметры длительной мембранной памяти (временные константы затухания).

Точные численные значения можно смотреть в `Parameters.xml`; они подобраны в соответствии с примерами из статей.
