## CableNeuronMulti_Diameters_ver93 — влияние диаметра дендритов (версия 93)

**Путь:** `Bin/Configs/SpikeSamples/NM-Neurons/CableModel/CableNeuronMulti_Diameters_ver93`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **влияние диаметра дендритов на распространение сигнала** в многокомпартментной кабельной модели CSNM (версия 93). Конфигурация является вариантом `CableNeuronMulti_Diameters` с параметрами версии 93 библиотеки NMSDK.

Согласно [2] и `CSNM-Models.md`, диаметр дендритов влияет на постоянную длины, сопротивление и скорость распространения сигнала. Данная конфигурация позволяет количественно изучить эти эффекты с параметрами версии 93.

### Структура модели

Конфигурация содержит кабельный нейрон с параметрами версии 93 для изучения влияния диаметра дендритов.

### Отличия от других версий

Данная конфигурация использует параметры версии 93 библиотеки NMSDK. Для сравнения с другими версиями см.:
- `CableNeuronMulti_Diameters` — базовая версия
- `CableNeuronMulti_Diameters_ver94` — версия 94
- `CableNeuronMulti_Diameters_ver95` — версия 95
- `CableNeuronMulti_Diameters_ver101` — версия 101
