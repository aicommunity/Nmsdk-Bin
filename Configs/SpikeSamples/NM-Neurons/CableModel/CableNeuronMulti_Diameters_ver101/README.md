## CableNeuronMulti_Diameters_ver101 — влияние диаметра дендритов (версия 101)

**Путь:** `Bin/Configs/SpikeSamples/NM-Neurons/CableModel/CableNeuronMulti_Diameters_ver101`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **влияние диаметра дендритов на распространение сигнала** в многокомпартментной кабельной модели CSNM (версия 101). Конфигурация содержит несколько нейронов (`NPulseNeuronCableMulti`) с различным диаметром дендритов для сравнения их поведения.

Согласно [2] и `CSNM-Models.md`, диаметр дендритов влияет на постоянную длины, сопротивление и скорость распространения сигнала. Данная конфигурация позволяет количественно изучить эти эффекты с параметрами версии 101.

### Структура модели

Конфигурация содержит несколько кабельных нейронов с различным диаметром дендритов (версия 101), аналогично версии 95, но с параметрами версии 101 библиотеки NMSDK.

### Отличия от других версий

Данная конфигурация использует параметры версии 101 библиотеки NMSDK. Для сравнения с другими версиями см.:
- `CableNeuronMulti_Diameters` — базовая версия
- `CableNeuronMulti_Diameters_ver93` — версия 93
- `CableNeuronMulti_Diameters_ver94` — версия 94
- `CableNeuronMulti_Diameters_ver95` — версия 95
