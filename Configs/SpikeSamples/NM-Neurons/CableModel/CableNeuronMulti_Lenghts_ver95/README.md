## CableNeuronMulti_Lenghts_ver95 — влияние длины дендритов (версия 95)

**Путь:** `Bin/Configs/SpikeSamples/NM-Neurons/CableModel/CableNeuronMulti_Lenghts_ver95`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация демонстрирует **влияние длины дендритов на распространение сигнала** в многокомпартментной кабельной модели CSNM (версия 95). Конфигурация является вариантом `CableNeuronMulti_Lengths` с параметрами версии 95 библиотеки NMSDK.

**Примечание:** В названии конфигурации используется вариант написания "Lenghts" (с опечаткой), что соответствует оригинальному названию. Аналогичная конфигурация с правильным написанием: `CableNeuronMulti_Lengths_ver95`.

Согласно [2] и `CSNM-Models.md`, длина дендритов влияет на задержку и затухание сигнала при распространении от синапса к соме. Данная конфигурация позволяет количественно изучить эти эффекты с параметрами версии 95.

### Структура модели

Конфигурация содержит кабельный нейрон с параметрами версии 95. Структура аналогична другим версиям, но использует параметры версии 95 библиотеки NMSDK.

### Отличия от других версий

Данная конфигурация использует параметры версии 95 библиотеки NMSDK. Отличия могут включать:
- Изменения в реализации кабельного уравнения
- Изменения в параметрах по умолчанию
- Улучшения в численных методах решения кабельного уравнения
