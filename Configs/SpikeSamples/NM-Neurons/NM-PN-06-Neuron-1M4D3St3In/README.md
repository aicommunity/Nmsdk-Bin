## NM-PN-06-Neuron-1M4D3St3In — нейрон с одним соматическим участком и четырьмя дендритами

**Путь:** `Bin/Configs/SpikeSamples/NM-Neurons/NM-PN-06-Neuron-1M4D3St3In`
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Эта конфигурация реализует **спайковый нейрон с одним соматическим участком мембраны** (1M), четырьмя дендритами (4D), тремя синапсами (3St) и тремя входными каналами (3In). Она демонстрирует влияние дендритной структуры на реакции нейрона при минимальном размере сомы.

Согласно исследованиям реакций естественных нейронов, наличие множественных дендритов позволяет реализовать сложную пространственную суммацию сигналов и влияет на временные характеристики обработки входных импульсов. Данная конфигурация позволяет изучать влияние дендритной обработки на реакции нейрона с малой сомой.

### Структура модели

- **Нейрон:** `NPulseNeuron` / `NPNeuron1x4`
  - один соматический участок мембраны (`PNeuronMembrane11`);
  - четыре дендритных участка (`Dendrite1`, `Dendrite2`, `Dendrite3`, `Dendrite4`);
  - низкопороговая зона `NPulseLTZone` (генератор спайков);
  - генераторы возбуждающего и тормозного потенциалов `NConstGenerator`.
- **Мембраны:** `NPulseMembrane` / `NPulseMembraneCommon`
  - один соматический участок мембраны с парой ионных каналов;
  - четыре дендритных участка, каждый с каналами и синапсами;
  - возбуждающие каналы `ExcChannel` (`NPExcChannel`, Type = −1);
  - тормозные каналы `InhChannel` (`NPInhChannel`, Type = +1).
- **Синапсы:** `NPulseSynapse` / `NPulseSynapseCommon`
  - три возбуждающих синапса, подключённых к возбуждающим каналам на дендритных участках.

Упрощённая схема:

```mermaid
flowchart TD
    inputSpike1["Входной импульсный поток 1"] --> syn1["NPulseSynapse 1"]
    inputSpike2["Входной импульсный поток 2"] --> syn2["NPulseSynapse 2"]
    inputSpike3["Входной импульсный поток 3"] --> syn3["NPulseSynapse 3"]
    syn1 --> dendrite1["Дендрит 1"]
    syn2 --> dendrite2["Дендрит 2"]
    syn3 --> dendrite3["Дендрит 3"]
    dendrite1 --> membr["NPulseMembrane\n(сома)"]
    dendrite2 --> membr
    dendrite3 --> membr
    dendrite4["Дендрит 4"] --> membr
    membr --> lt["NPulseLTZone\n(порог P)"]
    lt --> outSpike["Выходной спайковый поток"]
    outSpike -->|обратная связь| membr
```

### Структурная и параметрическая адаптация

Согласно [A], модель нейрона со структурной адаптацией позволяет динамически изменять структуру связей между элементами нейрона. В данной конфигурации:

- **Структурная адаптация:** фиксированная структура с одним соматическим участком и четырьмя дендритами, демонстрирующая влияние дендритной обработки на реакции нейрона с малой сомой.
- **Параметрическая адаптация:** параметры мембраны, каналов и синапсов могут настраиваться для изучения различных режимов работы.

### Пластичность модели

Пластичность модели нейрона (раздел 2.5 диссертации Бахшиева) обеспечивается возможностью изменения весов синапсов и параметров мембраны. В данной конфигурации пластичность проявляется через:

- изменение эффективности синаптической передачи на дендритных участках;
- адаптацию параметров мембраны к входным сигналам;
- формирование различных паттернов активности в зависимости от дендритной структуры.

### Эксперимент и моделируемые реакции

- **Вход:** последовательности импульсов фиксированной амплитуды и длительности на трёх возбуждающих входах.
- **Наблюдаемые величины:**
  - частота выходных спайков;
  - форма мембранного потенциала на входе LT‑зоны;
  - влияние частоты входной стимуляции на число спайков в пачке;
  - задержка и затухание сигнала при распространении по дендритам;
  - сравнение с конфигурациями с большим числом соматических участков (NM-PN-04, NM-PN-05).
- **Ожидаемое поведение:**
  - при умеренных частотах входа нейрон генерирует пачки спайков;
  - наличие множественных дендритов влияет на временные характеристики обработки сигналов;
  - малый размер сомы может приводить к более высокой частоте генерации по сравнению с конфигурациями с большей сомой;
  - возможен эффект пространственной суммации сигналов от разных дендритов.

### Параметры модели

Основные параметры задаются в `Parameters.xml`:

- **Синапсы (`NPulseSynapse`):**
  - `PulseAmplitude` — амплитуда входных импульсов;
  - `SecretionTC`, `DissociationTC` — постоянные времени выделения и распада медиатора;
  - `InhibitionCoeff`, `Resistance`, `UsePresynapticInhibition` — эффекты пресинаптического торможения.
- **Каналы (`NPulseChannel`):**
  - `Capacity`, `Resistance`, `FBResistance`, `RestingResistance`;
  - `Type` = −1 для возбуждающих каналов.
- **Мембрана и LT‑зона:**
  - `FeedbackGain` — глубина обратной связи;
  - порог LT‑зоны `P` и временные константы генератора;
  - параметры для соматического участка и четырёх дендритных участков.

Точные численные значения можно смотреть в `Parameters.xml`; они подобраны в соответствии с примерами из статей.
