## MultiPositionControl_SoloModeTest — многопозиционное управление (одиночный режим)

**Путь:** `Bin/Configs/SpikeSamples/MC1-PCN/MultiPositionControl_SoloModeTest`  
**Статус валидации:** VALID (см. `Reports/SpikeSamples-Validation-Report.md`)

### Назначение конфигурации

Конфигурация иллюстрирует многопозиционное управление в «одиночном режиме» (solo mode), когда активен только один из нескольких контуров управления или один исполнитель, при сохранении многопозиционной логики.

Она полезна для:

- анализа поведения одного канала управления в многоканальной архитектуре;
- отладки механизмов выбора цели и обратной связи без влияния других каналов.

### Структура модели (концептуально)

Структура похожа на `MultiPositionControl_SimpleTest`, но:

- активен только один канал/исполнитель;
- остальные либо отключены, либо находятся в режиме наблюдения.

### Эксперимент и моделируемые реакции

- **Сценарий:** перебор нескольких целевых положений в рамках одного канала.
- **Наблюдается:**
  - корректность переключения между целями;
  - устойчивость положений;
  - отсутствие нежелательного влияния со стороны неактивных каналов.
