# NNeuronLearner fixed-topology threshold probe (0.009)

Replay the completed medium-spread structural-learning model with training disabled. The saved topology and all physical model parameters are kept fixed. Only the LTZone threshold and its Learner fixed-threshold fields are changed. The passive recorder captures LTZone output and potential for 10.5 seconds.

Run from this directory with `NeuroModelerConsole.exe -c Project.ini -s -t 10.5 -x -S`.
