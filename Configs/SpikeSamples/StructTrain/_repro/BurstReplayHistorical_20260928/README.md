# Исторический порог LTZone: 0,0047

Дата: 2026-09-28. Release-консоль, до трёх параллельных процессов. Это парный контроль к пулу с порогом 0,0085. В обоих пулах использованы те же сохранённые структуры, входные строки, порядок паттернов, синапсы и модельные параметры. Менялся только порог LTZone и пассивная диагностика.

## Набор опытов

20 конфигураций: AllProbes On/Off (2), Iris10 и три Iris-прототипа (2), синтетические выходы On/Off (2), длины дендрита D3/D8/D17 с торможением On/Off (6), число синапсов 6/12/24/37 с торможением On/Off (8). Всего проверено 85 ответных окон.

Во всех конфигурациях рекордер подключён непосредственно к LTZone.Output трёх обученных нейронов. Анализатор проверяет сериализованные связи, заголовки сигналов в CSV, фактические биты output_data.txt и ожидаемые классы.

## Результат

Во всех 20 конфигурациях обнаружены повторные импульсы в ответном окне. Максимум — четыре восходящих фронта одного нейрона. Ни одна из 85 строк не совпала со строгим ожидаемым вектором класса (0/85). То есть при пороге 0,0047 выходные биты отражают пачечную активность и не могут считаться строгим one-hot ответом.

Подробное сравнение с парным пулом приведено в [classifier_threshold_comparison.csv](../classifier_threshold_comparison.csv). Сводка по этому пулу — в [burst_replay_summary.csv](burst_replay_summary.csv).

## Повторение

Подготовьте свежий каталог, не перезаписывая существующие результаты. Скрипт подготовки парных прогонов: [prepare_burst_exclusion_replays.py](../ClassifierDynamicsAudit_20260928/prepare_burst_exclusion_replays.py). Для синтетики и Iris он принимает порог через параметр --threshold; для перебора синапсов — через --fixed-threshold. Варианты длины ветви создаёт [prepare_dendrite_length_threshold_variants.py](../ClassifierDynamicsAudit_20260928/prepare_dendrite_length_threshold_variants.py). Запуск ограничивается тремя Release-консолями через [run_burst_excluded_batch.py](../ClassifierDynamicsAudit_20260928/run_burst_excluded_batch.py). Анализ обеих парных серий выполняет [analyze_classifier_threshold_pools.py](../ClassifierDynamicsAudit_20260928/analyze_classifier_threshold_pools.py).

Данные этой папки не являются выводами по неверно подключённым ранним рекордерам: прямые LTZone-связи и соответствие выходных битов проверены анализатором.
