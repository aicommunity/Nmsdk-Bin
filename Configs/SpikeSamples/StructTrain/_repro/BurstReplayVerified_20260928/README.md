# Проверенный пул LTZone при пороге 0,0085

Дата: 2026-09-28. Release-консоль, не более трёх параллельных процессов. Порог 0,0085 — экспериментальное значение для NSPNeuron в этих сохранённых структурах. Этот пул является парным к [историческому порогу 0,0047](../BurstReplayHistorical_20260928/README.md).

## Состав и проверка

В пуле 20 конфигураций на тех же структурах и входах, что и в историческом. Покрыты AllProbes On/Off, Iris10 и три Iris-прототипа, синтетические выходы On/Off, дендриты D3/D8/D17 On/Off, 6/12/24/37 синапсов On/Off. Всего 85 ожидаемых ответных окон.

Сигналы рекордера напрямую подключены к LTZone.Output всех трёх нейронов. Анализатор сверяет ссылки Model_00.xml, колонки signals.csv, каждую строку output_data.txt и число фронтов в окне. Все биты совпадают с LTZone-трассами, во всех клонах получены ожидаемые полные окна.

## Результаты

| Варианты | Строго правильные ответы |
|---|---:|
| AllProbes On и Off | 4/4 в каждом |
| Синтетические выходы On и Off | 4/4 в каждом |
| Iris10 | 8/10 |
| Три Iris-прототипа | 3/3 |
| D17, торможение On и Off | 4/4 в каждом |
| D8, торможение On и Off | 2/4 в каждом |
| D3, торможение On и Off | 2/4 в каждом |
| 6 синапсов, торможение On и Off | 3/4 в каждом |
| 12, 24 и 37 синапсов, On и Off | 4/4 в каждом |

**Пачек не обнаружено в 20 из 20 конфигураций**: максимум — один фронт каждого LTZone на ответное окно. При D3 один вход даёт два активных класса (битовая строка 110), хотя каждый нейрон выдаёт только один спайк. Значит, устранение пачек не обеспечивает разделимость. Iris10 даёт восемь строгих совпадений из десяти: один паттерн остаётся без ответа, один отнесён к неверному классу.

Полные парные результаты и исторический контроль: [classifier_threshold_comparison.csv](../classifier_threshold_comparison.csv), [BurstReplayHistorical_20260928](../BurstReplayHistorical_20260928/README.md). Машинная сводка этого пула: [burst_replay_summary.csv](burst_replay_summary.csv).

## Воспроизведение

Создавайте новые каталоги: завершённые проекты после EOF сохраняют DataFromFile=0. Генератор [prepare_burst_exclusion_replays.py](../ClassifierDynamicsAudit_20260928/prepare_burst_exclusion_replays.py) подготавливает Iris, синтетические и фиксированные структуры. [prepare_dendrite_length_threshold_variants.py](../ClassifierDynamicsAudit_20260928/prepare_dendrite_length_threshold_variants.py) подготавливает D3/D8/D17. Клоны запускает [run_burst_excluded_batch.py](../ClassifierDynamicsAudit_20260928/run_burst_excluded_batch.py) с batch-size 3; [analyze_classifier_threshold_pools.py](../ClassifierDynamicsAudit_20260928/analyze_classifier_threshold_pools.py) сравнивает новые и исторические результаты.

На время расчёта фиксированные модели не обучались. Число синапсов, дендритные длины и физические параметры нейронов не менялись; варьировался только LTZone threshold и пассивная запись сигналов.
