### Структурное обучение NNeuron

Проект содержит два учебных компонента: `NNeuronLearner` обучает структуру на четырёх временных задержках, а `NNeuronTrainer` — на пяти входах, где последний служит калибровочным. Сохранённые флаги включают обучение. Численные параметры внутренней модели не оптимизируются.

Для воспроизводимой проверки используйте копии из [`SpikeSamples/StructTrain/_repro/NNeuronTrainingReplay`](../../SpikeSamples/StructTrain/_repro/NNeuronTrainingReplay/README.md), которые сохраняют результаты отдельно. Там же есть вариант `UseAutoPreset=1` для холодного старта.
