### Результаты теста интервального сохранения

Это каталог снимков, полученных при двух последовательных тестовых запусках `NNeuronLearner` с `ProjectAutoSaveModelTimeInterval=2`. Вторая проверка продолжила структуру первого промежуточного снимка; эти файлы предназначены для анализа фактических записей, а не для чистого сравнения с нуля.

Release-прогон до 12 модельных секунд записал промежуточные снимки на времени 3, 6, 9 и 12 секунд. Файл `autosave-watch.stderr.log` содержит строки таймера, а наблюдение во время расчёта подтвердило изменение `Model_00.xml` и `Parameters_00.xml` до заключительного `Project saved.` Финальное состояние: `IsNeedToTrain=0`, `DendriteLength=[4,3,2,1]`, `NumSynapse=[19,7,4,1]`.

Для чистого повтора используйте `TestTrain_LearnerOnly_AutoSaveFresh`.
