# NSpikeClassifier synthetic class-output trace (inhibition off)

Clone of the paired synthetic classifier configuration. The 30-signal recorder was reduced to the three output LTZones only, one column per class, without changing classifier wiring, input data, trained neuron subtrees, or physical parameters. `DataFromFile=1` is enabled in this clone so the four rows in `input_data.txt` are actually presented. The project runs for 8.01 model seconds so the classifier flushes all four response rows before the run stops.

CSV: `ClassifierDynamics/LTZOutputsOff_20260927.csv`. The updated recorder adds each actual source path in brackets in the CSV header. `output_data.txt` contains the classifier's latched per-window bit vectors; it is regenerated by the same run as the CSV.
