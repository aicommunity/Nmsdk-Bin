# NSPNeuron: один активный синапс на терминальной ветви

Контрольный replay финального результата обучения NNeuronTrainer на синтетическом TTFS-паттерне. Класс нейрона и сохранённые параметры/длины ветвей оставлены как в обученном шаблоне `NSPNeuron` + `NPulseLTZoneThreshold`. В `Model_00.xml` отключены входные связи дополнительных терминальных ExcSynapse2..N и их связи с ExcChannel; ExcSynapse1 на каждой терминальной ветви остаётся подключённым к своему Source. Это контроль влияния параллельно подключённых синапсов при той же сохранённой длине дендритов. Параметры модели не изменялись. Время проверки — 6 модельных секунд; LTZone записывается в `TrainerSpikeProbe/ltz.csv`.
