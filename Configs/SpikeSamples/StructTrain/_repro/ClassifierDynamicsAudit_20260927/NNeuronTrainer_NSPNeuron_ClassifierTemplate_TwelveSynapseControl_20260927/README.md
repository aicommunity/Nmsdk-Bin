# NSPNeuron: 12 активных синапсов на терминальной ветви

Контрольный replay финального NNeuronTrainer на сохранённой структуре и параметрах. Длина дендритов, тип NSPNeuron, LTZone и параметры модели неизменны. Для каждого источника отключены терминальные ExcSynapse13..N и их выходы к ExcChannel; первые 12 синапсов остаются подключёнными. Время — 6 модельных секунд; LTZone в TrainerSpikeProbe/ltz.csv.
