# NSPNeuron: 8 активных синапсов на терминальной ветви

Контрольный replay финального NNeuronTrainer на сохранённой структуре и параметрах. Длина дендритов, тип NSPNeuron, LTZone и параметры модели оставлены неизменными. С каждого источника отключены связи к терминальным ExcSynapse9..N и выходы этих синапсов к ExcChannel; первые 8 синапсов каждой ветви остаются активны. Проверяется только влияние числа параллельно подключённых синапсов. Расчёт длится 6 модельных секунд, LTZone записывается в TrainerSpikeProbe/ltz.csv.
