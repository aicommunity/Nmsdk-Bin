# Повтор W-кейса на текущем C++-тренере

`replay_w_case.py` готовит отдельную копию входов одного W01–W04 случая, выполняет SoftCold reset штатным `repro_cold_lib.py`, запускает `NeuroModelerConsole` через `posttune_verify.py` и сохраняет provenance в `_repro/runs/<case>_<UTC>/replay_summary.json`.

Скрипт не реализует обучение и не меняет состояние тренера самостоятельно. Все изменения сопротивлений, длин и фаз выполняет C++-тренер. Исходные архивные входы используются только как источник копии; перед и после запуска сохраняются хеши файлов.

Пример одного процесса:

```powershell
python .\replay_w_case.py --case W04_BR100_N1_PSIoff
```

Для параллельной волны запускать отдельные процессы для разных `--case`, не более восьми одновременно. По умолчанию используются текущий Console, autosave раз в одну секунду модельного времени, предел 401×30 секунд ожидания и остановка после десяти последовательных autosave без изменений длины и TipR на Rmax. Фактическое завершение обучения определять по `Need=0`; достижение метрик качества записывать отдельно.

Полные raw-логи и рабочие копии остаются в игнорируемом `_repro/runs`. В Bin коммитить только выбранные входные конфиги, краткий сводный JSON/Markdown и этот запускатель, если он нужен для воспроизводимости.
