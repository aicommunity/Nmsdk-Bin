# P1 delay_t1ms__f20000

Подготовленный исходный конфиг; новое исполнение модели не выполнено.

Компонент NAxoneDelay, DelayTime=0.001; частота расчёта 20000 Гц.

Источник — стандартный NPulseGenerator (образ NPGenerator), 10 Гц, ширина 1 мс, амплитуда 1. Окно базового опыта 0,5 с.

На .15 сначала проверить частоту, структуру после Build и реальные связи. Скопировать весь комплект в отдельный каталог запуска вне исходников. Запускать модель только из рабочей копии конфига. Не сохранять автосостояние или журналы в Bin/Configs.
