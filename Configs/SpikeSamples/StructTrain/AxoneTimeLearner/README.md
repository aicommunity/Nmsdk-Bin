# Конфиги аксонного исследования

Здесь сохраняются воспроизводимые исходные конфиги и компактные объявления условий. План, протоколы P0–P8 и состояние исполнения находятся в [корневой документации](../../../../../Docs/StructTrain/AxoneTimeLearner/README.ru.md).

## Подготовленная серия P1

`protocols/P1-component-baseline.json` задаёт первые 45 условий: 15 исторических случаев Delay/Chain/ChainAndDelay при 2000, 20000 и 40000 Гц. Это базовая периодическая проверка, не полное покрытие P1.

`P1/component-baseline/<case_id>` содержит project.ini, Model_00.xml, Parameters_00.xml, Interface.xml, History.xml, condition.json и README. Стандартный генератор задаётся существующим образом NPGenerator, реализованным NPulseGenerator. Нейрон-источник отсутствует.

## Повторное формирование

Из корня Nmsdk:

```powershell
python -I -S -B -X utf8 Scripts/StructTrain/AxoneTimeLearner/generate_component_configs.py
```

Команда читает точные Git blobs объявленного Bin commit и формирует только входные файлы. Она не запускает NeuroModeler, сборку или эксперимент. При отличающемся существующем исходном файле команда отказывает; намеренную перегенерацию новой версии выполнять с проверкой diff.

## Исполнение

Сначала перенести через origin точные исходники и конфиги на .15. В реальном сеансе исполнения проверить SDK/runtime, загруженные DLL, частоту, структуру после Build, связи и фактические события. Научный статус подготовленных конфигов — prepared_requires_native_validation.

Скопировать полный комплект нужного условия в отдельный каталог запуска вне исходников. Только там выполнять штатный Console и сохранять его результаты. Не запускать старый setup_cells.sh: он дополнительно вызывает Console и меняет подготовленные конфиги.

Архивировать результаты в E:\Nmsdk-AxoneTimeLearner-Data на сервере .15 с проверкой его archive.root.json и серийного номера тома. Прежний M40-marker относится к другому хранилищу. Возвращать в Git компактные метаданные и *.archive.json. StatisticLog, EventsLog, автосохранённые модели, runtime и полные галереи в этот каталог не добавляются.

## Полная воспроизводимость

Для следующей серии сохраняются её собственный протокол, все фактические паттерны, начальная структура или компактный рецепт, профили, seed, порядок, ограничения и калибровка. Повтор обучения и повтор оценки сохранённой модели — отдельные операции. Файл с null scientific_result не является результатом нового опыта.

## Подготовленные следующие входы

`protocols/P1-native-contracts.json` описывает 45 линейных и 6 древовидных native-условий плюс lifecycle-фильтры. Источник имеет Delay=10 мс; это отдельная фикстура относительно базовых сериализованных проектов с Delay=0. Для повтора нужен точный исходный commit и серверная сборка соответствующего GTest target. Проверки пока не исполнялись.

`P2/historical-patterns/span{25,50,100,200,480}ms.json` содержит точные исторические паттерны из закреплённых Git blobs, восьмипаттерновую матрицу, префиксы и пропуски. Учитывается слой Parameters_00.xml. Эти файлы — входные рецепты; до научного запуска ещё нужны native-материализатор и объявленные принимающие/измерительные настройки.

`stage-source-manifest.json` хранит контрольные суммы. Повторное формирование только входных файлов:

```powershell
python -I -S -B -X utf8 Scripts/StructTrain/AxoneTimeLearner/generate_stage_configs.py
```

Эта команда не собирает и не запускает модель или тесты. Источники тестов должны соответствовать объявлению; разные существующие файлы без --overwrite не заменяются.
