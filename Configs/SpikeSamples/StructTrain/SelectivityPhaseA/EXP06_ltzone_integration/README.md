# EXP06 — тип компонента LTZone и временная интеграция

Inference-only: в Model задаётся **тип компонента** LTZone (C++-имя, не `target_class` датасета) и параметры интеграции/порога.

- Задуманное имя `NPulseLTZone` **не зарегистрировано**; рабочий интегратор — **`NPLTZone`** (`TimeConstant` = сглаживание до порога).
- Сетка: `TimeConstant ∈ {0.001, 0.00144, 0.003}` × `Threshold ∈ {0.0115, 0.012, 0.013}`.
- Подпапки `Test_tc<TC>_thr<THR>/` с `Class=NPulseLTZone` фактически fallback на мгновенный порог.
- Рабочие: `Test_npltzone_tc000144_thr00115` (4/8), `…_thr00135` (**6/8**, как EXP01). Канонический `Test/` — один из вариантов сетки.
